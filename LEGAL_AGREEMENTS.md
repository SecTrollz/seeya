## 7. IMPORTANT LEGAL NOTES

**DISCLAIMER:** This is a template. You should have a licensed attorney in your jurisdiction review these terms before use. State and country laws vary.

**When to add more terms:**
- If handling sensitive data (health, financial) → Add more data protection clauses
- If operating in EU → Add GDPR-specific terms (DPA, cross-border transfers)
- If serving healthcare providers → Add HIPAA-specific terms
- If in California → Add detailed CCPA terms
- If handling contracts → Add confidentiality and IP ownership clauses

**What this template DOES:**
✅ Collect explicit consent (checkbox + signature)
✅ Limit your liability to amount paid
✅ Disclaim warranties and guarantees
✅ Require binding arbitration (faster resolution)
✅ Address data privacy
✅ Comply with UETA/E-SIGN for electronic signatures

**What this template DOES NOT:**
❌ Provide legal advice (not a lawyer document)
❌ Comply with all jurisdictions (you need to customize)
❌ Handle industry-specific regulations (healthcare, finance, etc.)
❌ Protect against gross negligence or willful misconduct
❌ Replace proper insurance

## 8. DEPLOYMENT IN n8n

**In the `agreementPage` form node:**

1. Find the form field "agreement_terms" (dropdown or text area)
2. In the field description/label, paste the HTML code from Section 5
3. Mark field as required
4. Set form timeout to 86400 (24 hours)
5. Test: Fill out form and verify collapsible sections work

**Email delivery (if you add SendGrid email node):**

1. Use HTML version in email body
2. Include plain-text fallback for email clients that don't support HTML
3. Add digital signature or company stamp
4. Include link back to form for easy access
